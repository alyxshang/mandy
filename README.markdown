# MANDY

![Mandy CI](https://github.com/alyxshang/mandy/actions/workflows/rust.yml/badge.svg)

***A fast and light static-site generator.***

## ABOUT

This repository contains the source code for a light and fast
static-site generator (SSG) using the [Jirai](https://github.com/alyxshang/jirai) markup language and the [JMU](https://github.com/alyxshang/jmu) data language. The SSG has been optimized to be exceptionally light and exceptionally fast.

## CODE REPORT

***Mandy*** was built with the explicit purpose of being
very light, highly optimized, and very fast. These metrics
about the project's code should illustrate this:

- 700 lines of Rust.
- 160 lines of Rust unit tests.
- 779 lines of documentation comments.
- The size of the compiled binary is less than 500KB.
- The build time for a Mandy project is <400ms.

The previous version of Mandy from two years ago had 4000 lines of code and an executable size of 12MB.
